# Деплой демо на Render

Эта папка — копия `../site`, подготовленная под Render. Исходный проект она не меняет
и в основном репозитории игнорируется (`/render-deploy/` в корневом `.gitignore`).

## Первый деплой
1. Создать **пустой приватный** репозиторий на GitHub (например, `maison-lumiere-demo`).
2. Отсюда:
   ```bash
   git add -A && git commit -m "Демо для Render"
   git remote add origin git@github.com:<аккаунт>/maison-lumiere-demo.git
   git push -u origin main
   ```
3. Render → **New → Blueprint** → выбрать репозиторий. Render прочитает `render.yaml` и создаст:
   - веб-сервис `maison-lumiere` (Node, free),
   - базу PostgreSQL `maison-lumiere-db` (free).
4. Ввести `ADMIN_PASSWORD` (Render спросит при создании) → **Apply**.
5. Через 3–5 минут сайт будет на `https://maison-lumiere.onrender.com` (или похожем адресе),
   админка — `/admin` (логин `admin`).

При старте сервиса автоматически: применяются миграции → если база пустая, загружаются
демо-данные → график мастеров продлевается по шаблону недели на 28 дней вперёд.

## Обновить демо после правок в site/
```bash
./render/sync.sh
git add -A && git commit -m "Обновление" && git push   # Render задеплоит сам
```

## Особенности бесплатного тарифа
- Сервис **засыпает через 15 минут** без запросов; первое открытие — ~30–60 секунд.
  Перед показом заказчику откройте сайт заранее.
- **Бесплатная база Render удаляется через 30 дней** (можно перейти на платный тариф или пересоздать).
- **Загруженные фото мастеров пропадают** при перезапуске/передеплое (диск не постоянный).
  Для продакшена нужен Persistent Disk (платно) или S3-хранилище.
- SMS не подключены (как и в основном проекте).
