# Maison Lumière — сайт студии красоты с онлайн-записью

Требования: `../materials/srs.md`.

## Стек
Next.js 15 (App Router, Server Actions) · TypeScript · Tailwind CSS 4 · PostgreSQL + Prisma 6 · Vitest · Playwright.
Шрифты (Cormorant Garamond, Manrope) хранятся локально через @fontsource.

## Запуск
```bash
npm install
cp .env.example .env          # указать DATABASE_URL и пароль администратора
npx prisma migrate dev        # создать таблицы
npm run db:seed               # демо-данные (ОЧИЩАЕТ базу)
npm run dev                   # http://localhost:3000
```
Админка: http://localhost:3000/admin (логин/пароль — `ADMIN_LOGIN` / `ADMIN_PASSWORD` из `.env`).

## Тесты
```bash
npm test                                          # логика слотов (AC-02.2, 02.5, 10.1, 10.2)
npm run db:seed && E2E_BASE_URL=http://localhost:3000 npm run test:e2e   # сквозные сценарии по критериям приёмки
```

## Как устроено
- **Клиент**: регистрация и вход по телефону + паролю; запись возможна только из личного кабинета.
  В кабинете — предстоящие визиты, перенос, отмена, история.
- **Расчёт слотов** — `src/lib/slots.ts`: 14 дней, шаг 30 минут, не ближе чем за 2 часа,
  услуга должна закончиться до следующей записи и конца рабочего дня.
- **Двойная запись** исключена: создание/перенос идут в транзакции с блокировкой по мастеру
  (`pg_advisory_xact_lock`), свободность проверяется повторно внутри транзакции.
- **Цена и длительность** фиксируются в записи на момент бронирования.
- **Админка** (`/admin`): записи на день по мастерам (таймлайн + список), запись по телефону,
  перенос/отмена, график мастеров (шаблон недели → заполнение периода → правка отдельных дней),
  мастера (фото, услуги, скрытие), услуги (цена, длительность, мастера, скрытие), клиенты.
- **Фото мастеров** сохраняются в `uploads/` и отдаются по `/media/...`.
- **Время салона** — Москва (UTC+3), задаётся `SALON_UTC_OFFSET_MIN`.

## Заглушки, которые нужно заменить
- Название, адрес, телефон, часы работы — `src/config/salon.ts`.
- Текст политики конфиденциальности — `src/app/(site)/privacy/page.tsx`.
- Фото интерьера и мастеров (сейчас — тёплые градиенты и монограммы).
- Карта в блоке контактов.
- SMS-напоминания (US-07) и подтверждение телефона по SMS — не реализованы.
